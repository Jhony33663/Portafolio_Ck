PrestaTravel

  • Categoría: InsurTech & Web Transaccional
  • Cliente: PrestaTravel / PrestaSalud
  • Fecha de entrega: 12 Junio, 2026
  • Stack: Astro, React, Supabase, Payphone Payment Gateway, AXA API
  • Project URL: prestatravel.com

Plataforma digital para la contratación de asistencia en viaje y seguros médicos internacionales. Desarrollada con Astro para una velocidad de carga ultrarrápida e indexación SEO óptima, combinada con componentes React interactivos para el flujo de cotización en tiempo real. Integra pasarela de pago Payphone con webhooks idempotentes y conexión automática con AXA para la emisión digital instantánea de pólizas y vouchers de cobertura.
